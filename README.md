# Amino UI Clone

Frontend implementation of an Amino-style social/community app.

Foundation: Expo 54, React Native 0.81, Expo Router, NativeWind/Tailwind, TanStack Query, Zustand-ready state and Supabase.

Backend target: BACKEND (mauhdrdnlrvjkekxencu).

The frontend consumes the existing backend instead of creating a parallel backend.

Template foundation: https://github.com/seaguntech/seaguntech-expo-template
